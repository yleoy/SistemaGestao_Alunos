# 📌 Sistema de Gestão de Alunos

Aplicação que permite a leitura de arquivos **JSON** com informações de alunos,  
possibilitando a visualização, filtragem e classificação desses dados.

---

## ⚙️ Requisitos

- Necessário instalar a biblioteca externa **JSON-Simple**
- Version: json-simple-1.1.1.jar
  👉 [Download aqui](https://code.google.com/archive/p/json-simple/downloads)

---

## 🚀 Tecnologias

- Java 24
